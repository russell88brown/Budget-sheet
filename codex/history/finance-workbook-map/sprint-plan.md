# Finance workbook map

## Metadata
Russell owns the personal finance domain. This documentation sprint uses branch `sprint/finance-workbook-map`.

## Objective
Identify which budget inputs are private, which rules are maintained in source and how the engine produces its reports.

## Scope In
Map the observed workbook headers and the engine's documented responsibilities. Describe four proposed follow-on assignments.

## Task Checklist
- Check the input tabs, reports and source map.
- Trace the ownership of actuals, forecast rules, private inputs and synthetic tests.
- Describe dependencies and expected outcomes for the follow-on assignments.

## Acceptance Criteria
A contributor can place a posted payment, a proposed repayment rule and a synthetic test in their respective homes and identify the source for each.

## Definition Of Done
The document reflects the observed headers, distinguishes proposals from implemented behavior and passes the sprint documentation check.
